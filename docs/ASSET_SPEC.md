# 統一アセット制作仕様

この文書は今後作る素材の仕様です。現実装では画像生成・参照画像の転載を行っていません。

## 共通アート方針

明るいピンク、淡いブルー、ミント、クリーム。濃紺の細い輪郭、やさしい影、清潔な白背景UIに馴染む色。実在作品や配信者の容姿を再現しない。各人物の髪色・服のアクセントは `src/game/data.ts` のcolorを基準にする。

## 立ち絵（優先1）

- 指定12人をまず制作し、追加8人も同じ仕様で拡張する。
- 透過PNG / WebP、768×1024、正面、同じ頭身とカメラ距離。膝上・顔の位置・余白を統一する。
- 穏やかな笑顔、日常的な配信者衣装。各人物の個性は髪型・色・小物で区別する。
- 顔が細部まで読めること。UI内には画像の文字を焼き込まない。
- `hiyori-portrait.png`, `luna-portrait.png` のようにキャラクターidを使用。

## 箱庭ミニキャラ（優先2）

- 2.5頭身、透過128×176、足元中心、正面斜め向き、全員同じサイズ感。
- 通常立ち、歩行2〜4フレーム、配信・レッスン・休憩の差分を同じキャンバスで制作。
- 現在の実装は1枚のmini画像＋揺れの表示。歩行スプライトシート使用時は `renderOffice.ts` にフレーム切り出し処理を追加する。

## 施設（優先3）

- アイソメトリック、横84:縦44のタイル比、2×2マス占有。
- 透過画像。2枚の奥壁・家具・床を含め、手前の壁は省略して人物を見やすくする。
- 配信ブース、歌・トーク・企画レッスン、休憩、カフェ、マネージャー、スカウト、グッズ、撮影、受付、社長デスクの12種。
- ON AIRや看板文字はCanvasで重ねる方式が望ましい。差し替え後も活動状態表示を維持する。
- Lv2/3差分は小物や装飾追加で成長を表す。占有サイズ・基準点を変えない。

## 小物・ロゴ・音声

- 床、観葉植物、机などは施設と同じ投影角度。背景なし。
- ロゴは架空の「星むすびプロダクション」。現在はHTML文字＋オリジナルの星記号。
- 音声は権利確認済みのオリジナル素材のみ。BGMは自然にループできる音源。音量は初期OFFを維持。
- 音声パスは `assets.ts` の設定へ集約。実装済みのWeb Audio版は素材未用意時のフォールバック。
